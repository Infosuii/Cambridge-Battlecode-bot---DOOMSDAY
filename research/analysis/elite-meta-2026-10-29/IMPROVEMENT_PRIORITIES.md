## Isolated experiments to run only after implementation is requested

**E1: event-clock banking.** Build a source-identical control first. Add only a candidate to start tribute before an imminent payout while legally maintaining a region and usable altar. Cases: positive versus zero starting bag; Capture holder joining/leaving; simultaneous capture/channel zero; Tribute modifier; lock arrival; enemy stun; gate respawn. Metrics: exact countdown/receipt/score agreement, accepted actions, first useful score and whole-game final score. Success requires no pre-intervention divergence and no unsafe-start regression. Do not claim a twenty-tick arithmetic difference is twenty rounds of game benefit.

**E2: delivery scheduler.** Keep draft/items/farm targets fixed. Compare completion-time decisions against the baseline using cheap known-state inputs and conservative unknown threats. Pre-register ordinary dispersed maps, fragmented access and large-bag pressure. Metrics: banked score, terminal bags, loss transfers, time-to 1000, and productive camp cycles forfeited. Include rows-like low-combat races and Prism-like retained-capital cases as counterconditions. Reject a global early-bank fix if it destroys the latter role.

**E3: item taxonomy.** Compare one next-milestone choice on matched cluster-rich versus monster-only jobs; do not change draft or force receiver travel. Measure actual Prospector bonus counters, income before/after complete milestones, clear/recovery time, death-adjusted delivered score and final faults. Include rounding/split rewards. An early income increase without a delivered-score benefit is insufficient.

**E4: exact supplied-v69 regression.** The attached archive gives a precise starting point. Reproduce the original timer-conflict trace and the safe/dangerous recall controls, then test a bounded remedy. The conditional-v71 branch already differs, so inspect and reproduce it independently before proposing the same change there. The historical warm test did not prove a complete-match benefit.

**E5: local combat/fuel.** Separate target valuation from search cost. First run a behaviour-identical logging/control build at official fuel. Then change only one carrier/access term or one legal-sequence expansion. Metrics include action timing after suspension, original-trajectory fidelity, carrier losses and objective score. A faster controller with different actions is not a pure performance optimisation control.

Follow existing bench provenance/default-fuel rules, invalidate native faults, and use map/group-clustered uncertainty. Use only authorised development maps for tuning; final pools and the old research reserved 165 are already exposed/spent and must not be relabelled untouched. Freeze a candidate before any valid new holdout. External-opponent testing eventually matters because self-lineage performance is not elite strength, but this document does not authorise new match groups or deployments.
