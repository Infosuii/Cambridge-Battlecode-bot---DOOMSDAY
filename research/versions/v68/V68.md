## What the top teams do that we don't

From the 502-loss audit (`research/top-losses-20261026`), the Claudus study (`research/v58/V58_CLAUDUS_FINDINGS.md`), the
3,378-game top-vs-top crawl (`research/v66/META_TABLES.md`) and v65's own top-12 duel:

| | Top 12 | v65 |
|---|---:|---:|
| Deaths / kills per game | 5.1 / 13.6 | 14.9 / 3.6 |
| Team gold per game | 6,511 | 3,564 |
| Vesper capture gold by R250 (Claudus) | 466 | ~170 |
| Elk-size groups cleared by R250 | 4.0, from R21, 3-4 champions | 2.3, from R36 |
| First Bruiser shard (median, heroes that buy one) | R423 | R775; none before R300 in 105 losses |
| Draft | Vesper, Heart, Vendetta, Marcella in 80-100% of games | Vendetta, Varg, Marcella, Ren |

Their edge is one loop: a crew clears elk-size camps early, rewards go to a Treasure Vesper, her gold goes into raw
strength, and the stronger team then wins fights and farms faster. Pieces of that loop added one at a time to our
controller lost to our own lineage locally (v58 Claudus copies −52 to −217), and the few that reached the ladder
(v59-v66) all landed within noise of v65.

## Ladder test (needs the user's go-ahead: it makes each arm the live submission for about an hour)

```text
cambc submit bots/v68                       # becomes platform version N; note N
python tools/replay/ladder_duel.py run --plan research/v59/duel_top1.json --version N --arm v68
python tools/replay/ladder_duel.py run --plan research/v59/duel_top1.json --version 65 --arm v65r
python tools/replay/ladder_duel.py report --plan research/v59/duel_top1.json --arms v65r v68 --margins
python tools/replay/ladder_duel.py restore --version 65   # unless v68 wins
```

Release rule: v68 replaces v65 if its paired margin against the top 12 is clearly positive (more than about +50 gems,
the noise of one 120-game arm). If v68 shows the right mechanisms on the ladder (Vesper gold, fewer deaths) but not
yet the result, v68b is the next arm.
