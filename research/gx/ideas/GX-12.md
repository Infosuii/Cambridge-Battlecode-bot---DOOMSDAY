# GX-12: Build the camp catalogue in the draft

The heavy-map profile attributes 45–63k fuel to the first-turn group loop before most champion decisions start. Camp handles, positions, types and rewards are public, static map data. Reading them separately in every champion instance repeats work.

Serialize a compact catalogue once into a reserved part of the SDK's draft memory. Validate version, map dimensions, group count, payload length and checksum before use. Maps that cannot fit the catalogue use the original path. Respawn rules and design stats still come from the gameplay API. Compare every decoded record to native group and member reads in an instrumented sample before scoring a release build.
