Evidence: 64 new diagnostic games on all 16 frozen heavy development maps, both sides versus v92/x3inv. A2_TEL recorded 84 suspended-turn trails: 43 support-to-world-visibility, 13 support-to-ward completion, 18 farmmove-to-decision, three ward-to-ambush visibility, and seven other intervals. No suspension crossed duo_start/duo_end or td0/td1. The probe changes charged fuel and is diagnostic, not an equivalence or strength result. Raw traces: `artifacts/codex-p0/runtime-probe-v1/traces-v3.json`.

Mechanism: `bots/v92/src/world.cpp:185` labels static eight-connected bush components with repeated host calls to test membership and visited status. Replace only that component fill with a cached SDK packed linear occupancy buffer and a packed visited buffer. Preserve component numbering by first query, all eight neighbors, the existing label array, and the externally used labelled bitboard. No map names/dimensions as strategy keys, no changes to decisions, no delayed incomplete result.

Prediction: native fixture produces identical components and labels for every tile checked, and completes with less fuel. Two independent release builds must match; disabled switch must equal v92. Then run the official-pool L0 safety gate against the existing verified v92 arm, both sides. Any per-cell fuel increase blocks advancement. Only a surviving candidate gets diverse noise-aware L1/L2. The fresh holdout remains sealed. Never infer ladder strength from runtime or local wins.

The SDK comment for export_linear_buffer says one byte per tile, while linear_buffer_size returns ceil(width*height/8). Verify the actual packed bit order on the official engine before using it. The candidate contains no logging; equivalence probes are separate local builds.
