## Implemented

- The same eight-byte word now schedules cash, project and cohort messages. Each
  even-round frame spans the odd round; dated cohort records survive subsequent
  packets. Independent leaders have separate records and scheduled publication
  windows. Urgent initial offers preempt briefly; established crews no longer
  continuously monopolise the metadata word. Reports expire after `6*n+2` rounds.
- Existing positive task claims acknowledge an advertised roster; negative claims
  revoke an acknowledged record until a genuinely newer offer. Merely restoring
  the old objective code cannot resurrect it. Same-task workers can adopt the
  newest retained roster after the short invitation packet disappears. No record
  establishes unseen HP, damage, physical presence or future consent.
- Capture publishes a singleton recipient reservation while helpers leave. Both
  economy and legacy fallback avoid objectives owned by another current cohort.
  Idle/redundant outsiders yield away from observed crew working space, using
  actual ranges or immediate adjacency, occupied/spawn rejection and safety masks.
- A full-health body at home is no longer silently counted as a returning helper.
  Execution and macro quotes require its actual matching task claim. Missing task
  acknowledgements expire; a declined roster gets a finite back-off and re-auction.
  A new roster/generation can retry a previous solo/old-roster failure. The identical
  failed roster retains its existing avoidance window. Lost workers and blocked
  serial moves cannot hold a partial clear indefinitely; remembered HP is retained.
- Solo activity reports track real best approach distance, objective HP, captures
  and successful work across Contract resets. Re-selecting the same stalled job
  cannot keep advertising it as productive. Crew/siege recovery retains explicit
  owned-project intent instead of exposing the worker as idle shopping capacity.
- Public group and camp handles now define canonical shared ordinals. All member
  consumers use the same ordered view. This hardens identity; it was not shown to
  be the cause of the remaining side-A production failure.
- Both crew yielding and existing siege-lane yielding execute one guarded adjacent
  step, without generic Retreat's recall/cast/movement substitutions. Crew-space
  yielding cannot override an active siege task. The normal move reserve is checked
  again at execution; a planner's request never authorises a disallowed step.
