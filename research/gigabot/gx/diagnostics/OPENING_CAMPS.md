# Where early gems came from

[Replay counts](opening-camps.json) cover all 516 x3mf pool games through round 150. Use actual runtime groups and walking distance to both teams' starts to classify home, centre and enemy groups; keep groups unreachable from either start separate. The logged gold column is listed reward, not measured inventory.

| Opponent | Centre gem differential per win | Per non-win |
| --- | ---: | ---: |
| v92 | -0.3 | -1.4 |
| v86h | +4.7 | -7.4 |
| x1bru | +11.5 | -2.2 |

Centre ownership is associated with success against the latter two, but barely separates results against v92. In these logs it can be a consequence of an already stronger opening. Prefer a trigger that uses a visible, short advantage rather than a universal centre rush.
