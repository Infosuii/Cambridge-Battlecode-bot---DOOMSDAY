# GX-29: Rosters that match the work

Draft-only change. Arm 0 preserves the base picks. Compact maps can use close control; connected maps with long camp or altar travel favour mobility; large neutral HP loads justify a dedicated clearer. Arms 1–3 implement those three hypotheses; arm 4 combines them with a fixed precedence. The base pick path remains available and the normal memory layout is preserved.

Prior evidence: historical roster fingerprint predictions only classified 107 held-out matches and got 45 of those wrong. This policy classifies the map rather than naming the opposing team. Opening centre results vary sharply across opponents, so do not use a fixed centre rush. Record draft picks and observable differences as well as wins. Match executable sections across arms; compare each arm with control and x3mf on the same pool seeds. There is no new work on champion turns; the draft has its own meter.
