# GX-25: Reuse exact group-to-group distances from the draft

Route look-ahead lazily builds a distance row for each first target. Its geometry is static on a walking map. The draft can afford to compute those rows once for the team; symmetric walking distances let a 43-group table fit in draft memory.

Use one byte per unordered pair and fall back on unsupported layouts, bridges and long distances. The first native comparison disagreed on one-gem because live fields stop after a fixed maximum distance. Store the live depth cap and apply it when opening a row. After that correction, both teams matched native on the six selected maps with zero faults. A second strength variant deliberately makes precomputed rows available before live fields exist.
