# EXP-162 — Read current-engine replays with verified assets

The replay loader currently accepts only engines 1.0.3 and 2.0.0 and rejects `NFS_REPLAY_ENGINE=3.0.0`. Add engine 3 as an explicit opt-in using the official CLI5 visualiser assets and their SHA-256 hashes. Preserve both existing modes. Validate the decoder and native suspension recount on a current-engine development replay, then require the same engine-2 replay report bytes before and after the change. This is analysis infrastructure, outside production bot inputs or fuel accounting.
