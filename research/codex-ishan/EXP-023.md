# EXP-023 — Reuse exact siege sight rays

The [64-game farm trace](RUNTIME_WARD_DETAIL_FARM.json) records 17 crossings from siege preparation to entry into movement. The source scans 81 offsets per unprepared camp and recalculates up to three signed divisions per axis for each line-of-sight ray before movement. The existing direct bitboard setter can publish clear cells without the SDK call used by this loop.

Build the 81 relative rays at compile time with the original integer rounding and order. A ray has zero to three intermediate offsets. Use the exact same checks against the opaque grid and set the same clear bits. Preserve cache indexing, partial cache admission and the existing 30k check. A lower cost can make the loop finish more entries before the check, so later decisions are not assumed identical.

Require two exact release rebuilds, switch-off byte identity to v92 and the same 172-cell L0 gate. Predict fewer siege-preparation suspensions. Reject any per-cell fuel increase even if the total drops. Keep ladder, selection and holdout untouched until the appropriate gates pass.
