# I-60-02: first-turn fuel-outs on large many-group maps  [area: map-specific weaknesses]  — finding, parked

## Evidence
x1 (base gate cells): fuel-outs at round <= 1 = ladder 8 / 280 games (all on 00road-of-riches), styled 24 / 200 (all
gen6_0018), maze set A 96 / 116 (24 each on pc_maze_00, 16, 18, 23), maze set B 0 / 120. 24 per map = every champion
in all 4 games on that map. Same 96 under P4.
Profile (APEX_PROFILE, pc_maze_16: 71x71, 68 groups, 264 camps): World::init costs boards 4.5k + spawn_field 12.6k
+ **group_loop 105.5k** + tables 26.3k = ~149k of the 200k first champion turn; the rest of the first turn then runs
out. The group loop already uses the raw engine calls; its cost is per group (68 GroupRec with a whole-map bitboard
each; memory fills cost 1 fuel per byte) and per camp.

## Value
A first-turn fuel-out costs each champion about one round (the turn resumes next round), on 6 of 109 maps. Small; I
park it. If wanted: make the first turn stop after World::init when fuel_remaining() is below a threshold (no field
or bush work that turn), or allocate GroupRec::tiles lazily. Not built.
