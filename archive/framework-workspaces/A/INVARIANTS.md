# Teacher semantic invariants (Agent A)

Binding for every head, hook and capture. "Teacher" = the original bot (references/builds/original.wasm, code section
`02739407...0136`). Each invariant names how it is checked; "checked" means a test or measurement in this workspace,
"design rule" means it must be enforced by review/tests of the head code that does not exist yet.

| # | Invariant | How it is checked |
|---|---|---|
| I1 | **Teacher-exact build.** With every head `off`, `kFuelCredit=false`, `NN_STRIP_LAB=0` the Wasm is identical to the original (code section at least). | checked: patches 01, 02(off), 03 and 01+02+03 stacked give a byte-identical wasm (sha256 `eb0ea88f...4442`); `tools/audit_build_compare.py` |
| I2 | **Candidate 0 is the teacher's choice and is legal.** Every captured candidate array puts the teacher's choice first (`Objective::cand[0].gi == teacher`, `Draft.teacher` legal and a first maximum). | checked at runtime by `nn_teacher_access::check_objective/check_draft` in the capture self-test: 0 violations over 4 matches + 5 draft picks (`archive/agents/A/evidence/capture_selftest.json`) |
| I3 | **Teacher choice computed before the head.** A hook sits after the statement that finalises the teacher's choice (inventory `hook`), never inside the teacher's scoring loop. No head work (features, inference, logging) may run before the teacher's own fuel-gated stages of the same decision (`score_groups` route gate `kRouteFuel`, kDet scoring cap, `tactical_decide` playouts). | design rule; inventory hooks are placed after the loops; the v50 regression (features inside `score_groups`) is the counter-example |
| I4 | **Heads never bypass legality.** A head only selects among candidates the deterministic generator produced; execution keeps the original SDK calls and their failure fall-through (`move_absolute` false -> next candidate, `can_buy` before `buy`, ability range/cooldown/`cast_done`, A2_TD_AUTH unmodelled-risk rule). | design rule; candidate legality masks in `nnh::Decision` (B) |
| I5 | **Shared-memory layout unchanged.** 8-byte team word: 6 x 7-bit claims (bits 0-41), sighting x/y/round-mod-64 (42-61), distress (62), APEX_EVENTS group event flag (63; x field = group, y field = respawn round mod 256). Draft memory: brain header `{magic, team size, enemy casters, class, max group gems, flags}` (6 bytes). No head writes either. | checked for patches 01-03 (no edits to `read_shared/write_claim/write_order/share_sighting/record_draft`); `bot.h:21-28`, `strategy.h` record_draft |
| I6 | **Claim protocol unchanged.** A head that substitutes the objective writes the substituted group through the same `write_claim(best)` in `farm()`; codes 112-118 (fight orders), 126 (dead), 127 (idle) keep their meaning; heads never write claims themselves. | design rule; the objective hook is before the original commit statement |
| I7 | **Shadow is behaviour-neutral only up to fuel.** `shadow` executes the teacher choice, but any extra fuel (captures, features, inference, logging) can change the teacher's fuel-gated decisions. Neutrality must be demonstrated with `kFuelCredit` (teacher fuel queries see neural spend credited back) and measured with `tools/audit_equivalence.py`, not assumed. | checked: removing only lab exports/ctl checks (less fuel) changed 2/8 cells; full lab strip changed 20/24 cells (`agents/A/evidence/eq_strip_*.json`) |
| I8 | **Teacher fuel view.** Every decision-gating fuel read goes through `nnb::teacher_left()`; instrumentation reads stay raw. | checked: patch 01 routes 38 reads (bot.cpp 22, tsearch.cpp 13, world.cpp 1, draft.cpp 1, rb::left 1); remaining raw reads are listed in `tools/audit_fuel_routing.py LEFT_RAW`; all are instrumentation: inside compiled-out or constant-false blocks (APEX_PROFILE / A2_TEL / APEX_ESC* / APEX_TSLOG / `LOG` with APEX_LOG 0), except world.cpp:43, which runs once in `World::init` and whose value is only consumed by an `if (APEX_PROFILE)` print |
| I9 | **Captures are bounded, POD and side-effect free.** No SDK calls except the shop pre-pass (`can_buy`/`item_count`, read-only), no heap, fixed arrays (8 groups, 8 enemies, 8 steps, 12 draft picks), constant initialisation only. | checked: nn_teacher.h; build with all heads shadow compiles and runs without faults (4 matches, 0 bot faults) |
| I10 | **Captures are per turn.** An accessor returns data only for the current `round`; stale data is never served as the current teacher choice (`objective()` etc. return nullptr otherwise). The strategy head cannot know the current turn's chain branch before the chain runs: it uses candidate 0 = "teacher order" and the captured branch is the training label. | design rule + accessor code |
| I11 | **Commitment.** An off-teacher objective choice must not be silently re-committed by stickiness for many turns without being logged as a new decision each turn it is re-evaluated (v50 committed off-baseline choices for up to 40 rounds). `farm()` re-evaluates every non-low-fuel turn; heads must keep that cadence. | design rule (B/D logging) |
| I12 | **Determinism.** Same (wasm A, wasm B, map) gives an identical replay, summary and per-turn fuel trace. | checked: original vs original as side A and side B (two independent runs) identical on 12/12 maps; re-run of 8 v47 cells identical 8/8 |
| I13 | **Fixture sensitivity.** The equivalence comparator detects any behaviour change. | checked: first-hour vs reference 0/16 equal; NN_STRIP_LAB=1 20/24 different |

Release note: `NN_STRIP_LAB=1` is not teacher-exact (I1/I7); a release that strips the lab is a behaviour change and must be
evaluated as a candidate, not as the teacher.
